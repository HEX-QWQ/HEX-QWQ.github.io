MAGE 抗体生成模型的微调：三个检查点的同口径评测

在 1024-token 与 2048-token 两轮继续训练之后，MAGE 在 Ag3（PQ621839_F 278–444）上的 Top-20% ipTMA 从 0.202 提升到 0.270（+0.068，P ≈ 0.97），提升集中在高分区间的尾部。

1 微调数据来源 2 微调参数设置 3 测评基准设置 4 三个检查点的比较 5 结论与局限

主要发现。① 第二个 epoch 才带来可分辨的提升：epoch 1 相对基座 +0.011（P = 0.65，与噪声无异）， epoch 2 相对基座 +0.068（P = 0.967）。② 提升只发生在上尾：中位 0.120 → 0.115（略降）， 但 >0.4 的设计从 3 条增至 7 条、>0.3 从 4 条增至 11 条。③ 抗体可折叠性未变 （pTMbinder 中位三者均为 0.865），微调改变的是界面判断而非结构可行性。

1 微调数据的来源

微调沿用 MAGE 官方训练数据的注释版本，而不是原始 FASTA。数据主体是一份包含抗原序列与 配对抗体序列的表格 antibody.csv（29,354 行）。抗体序列由 ANARCI 按 IMGT 规则注释， 得到 30,582 条唯一注释序列。抗原与抗体的连通组由 MMseqs2（抗原 ≥80% 同一性、≥80% 双向覆盖）与 「相同 VH / 相同 VH–VL 对 / 同长度 HCDR3 ≥80% 位点同一性」共同定义，用于隔离训练集与验证集。

两轮数据的差别只在长度预算。长度按整条样本的 token 数计算，包含 BOS、抗原、 SEP、LC、EOS，既不截断抗原也不截断抗体；第一轮上限 1024 tokens， 第二轮放宽到模型原生的 2048，因此多接纳了一批含长 CDRH3 的记录。

隔离策略：历史验证记录中，若因新增长记录而与历史训练组产生连通关系，会被移入 quarantine（82 条）， 既不转入训练集、也不留在验证集。第一轮原有的 1,044 条验证记录仍保留，另有 6 条长记录进入验证集。 连通组划分基于序列相似性启发式，不能保证排除全部生物学同源关系，因此验证 loss 只作训练过程监控。

2 微调参数设置

两轮都是单卡、全参数（FP32 权重 + BF16 autocast）继续训练，超参数几乎一致，差别在起点与回放策略。 epoch 2 从 epoch 1 的权重继续，并恢复 AdamW 的一阶、二阶动量与已有步数，因此它不是一次重新开始的训练。

3 测评基准设置

评测沿用本组既定的抗体设计基准协议，只替换模型权重，其余全部固定。靶标为 Ag3 （PQ621839_F 278–444，167 aa，整段作为设计输入），任务为 ab（VH–VL 配对），每个 block 200 条。

环节设定
生成4 卡 × 70 = 280 条请求；top-p 0.9、T = 1.0、max_new_tokens 300
随机种子501 / 502 / 503 / 504（三个检查点完全相同）
框架 / 表位自由生成（de_novo_pair）；无表位条件（sequence_only）
过滤规则canonical 配对 → VH 110–130、VL 105–120 aa → 轻链完整（[LC] 后出现终止标记） → 配对唯一
选取按 batch 轮转取满 200 条，不做打分或人工挑选
复折叠AlphaFold3，5 recycle、1 diffusion sample、不使用模板；抗原链配官方 MSA，抗体链空 MSA
主指标ipTMA = max(ipTM[A][H], ipTM[A][L])，取 Top-40 均值（前 20%）
置信区间对 200 条设计 bootstrap 重采样 4,000 次，每次重算 Top-40，取 2.5–97.5 分位

三个检查点使用同一组种子与同一条流程，唯一变量是模型权重，因此差异可以直接归因于权重； bootstrap 区间反映的是「200 条里挑 40 条」的抽样噪声，不包含换种子的运行间波动。

5 结论与局限

四点结论

  • 两轮收益差异很大。epoch 1 基本等于噪声（+0.011，P = 0.65），epoch 2 才有实质提升 （+0.068，P = 0.967）。这与「第二个 epoch 才真正吃到 2048-token 长样本」一致：4,252 条长记录恰在这一轮纳入训练。
  • 提升只发生在上尾。中位 0.120 → 0.115（略降），均值 0.128 → 0.142，而 q95 0.210 → 0.310、 >0.4 由 3 条增至 7 条、>0.3 由 4 条增至 11 条。
  • 可折叠性没有变化。pTMbinder 中位三者均为 0.865（≥0.8 的比例 199 / 188 / 193）， 微调改变的是界面判断，而不是抗体自身能不能折。
  • 界面 PAE 首次接近可用线。最小 min ipAE 由 7.31 Å（epoch 1）/ 2.66 Å（base）降到 2.14 Å， 为三次中最好，但尚未达到 1.5 Å。

两点局限

  • 统计上仍是「接近显著」。ΔTop-40 的 95% CI 下界为 −0.004，略微跨 0；要把 +0.068 写成确定结论， 需要 3–5 个种子的重复实验。
  • 框架与表位都未受控。MAGE 是纯序列模型，输出框架自由、输入不含表位坐标， 与「结构条件化 + 四框架」的模型不是同一类问题，横向排名只能作为参考。

一句话总结。在 Ag3·ab 这一格上，第二个 epoch 的微调把 MAGE 的 Top-20% 从 0.202 提到 0.270 （+0.068，P ≈ 0.97），提升集中在高分区间的尾部，而抗体可折叠性与中等分设计几乎未变。
